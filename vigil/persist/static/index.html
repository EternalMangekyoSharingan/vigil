Vigil Persist what starts by itself

What Persist reads

systemd units and timers (system and yours), cron, XDG autostart, shell start-up files, /etc/ld.so.preload, PAM, sudoers, SSH keys and settings, kernel modules (configured and loaded), udev rules, and boot, network and package-manager hooks.

The first scan becomes the baseline. Later scans show what is new, changed or gone. Files that came from a package are checked against that package's own checksums where your distro's database can be read (pacman, dpkg).
